# Glasfaser WebApp

Einseitige Web-App (eine HTML-Datei, ohne Server) für die Verwaltung von Glasfaser-Bauarbeiten: Termine, Arbeiten, Adressen, Kabel, Aufmaß.

Одна HTML-страница без сервера. Данные хранятся только в браузере пользователя (localStorage) — в репозитории данных нет.

- Версия: 43.1 (`index.html`)
- Ветка `Test` публикуется через GitHub Pages — для удалённых проверок.
- Обновления ставятся файлами `.gfu` через «Настройки → Обновление программы».
